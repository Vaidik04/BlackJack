# 🃏 Blackjack Game (Python)


A fun **command-line Blackjack game** built using Python!  
Play against the computer, try to get as close to 21 as possible, and test your luck — just like in a real casino 🎰  

---

## 🚀 Features
- ♠️ Draw random cards like a real deck  
- 💻 Computer acts as the dealer  
- 🎯 Detects **Blackjack (Ace + 10)** instantly  
- ⚖️ Automatic score calculation and comparison  
- 🔁 Option to play multiple rounds  
- 🎨 Includes ASCII art logo (from `art.py`)

---

## 🧰 Requirements
Make sure you have:
- **Python 3.x** installed
- The `art.py` file (for the game logo)

Install dependencies if needed:

pip install art
